# 脑洞小剧场 · SillyTavern 扩展

输入脑洞 → 独立 API 整理成小剧场创作指令 → 编辑、保存 → 通过酒馆的用户发送键发出 → 当前角色创作小剧场。

## 安装

需要 SillyTavern 1.13.0 或更新版本，建议使用近期版本。

1. 在酒馆的「扩展」页面点「安装扩展」。
2. 粘贴本仓库的 GitHub 地址，安装完成后刷新酒馆。
3. 在扩展设置或输入框旁的扩展菜单中打开「脑洞小剧场」。
4. 在「API 设置」中填写 OpenAI 兼容的 API 基础地址、密钥和模型名称，点击「保存设置」，可点「测试连接」。例如地址为 `https://api.example.com/v1`。

无需构建、npm 安装或酒馆助手。`manifest.json` 与 `index.js` 必须在仓库根目录；单独改 HTML 的文件名不能成为扩展。

## 功能

- 自动读取当前角色卡、用户设定和最近 20 条非系统聊天；群聊会读取成员资料。
- 独立请求 Chat Completions，使用本扩展的提示词预设和输出上限，不调用酒馆当前的聊天生成预设。
- 内置提示词将脑洞整理为「创作指令」，不预先生成故事正文。默认目标约 300 字，上限 1024 token；均可编辑、保存多组预设。
- 可一次生成 1–10 条，支持停止、编辑、重生成、保存和发送。发送后角色正常回复的阶段仍使用酒馆自己的聊天配置。
- 前缀和后缀可新建、编辑、保存，多选叠加并调整顺序；可保存整个组合。选择窗口每排两条，约八条可见，继续向下滚动。
- 日间、夜间各四款配色，各自记住上次选择；支持导入自定义美化，导出当前选中的美化分享。
- 分别保存小剧场指令和角色回复；收藏可搜索、编辑、复制。角色消息操作栏新增书签按钮，点击即可收藏当前回复；也支持手动粘贴收藏。
- 导出 / 导入 JSON 备份，可合并去重或覆盖恢复；支持先前界面预览版导出的备份。

## 自制与分享美化

在「美化」窗口选择配色，点击「导出当前美化」下载独立 JSON 文件。文件只包含这一套美化的名称、日夜模式和界面色值，不含 API 设置、收藏或聊天内容。

别人可修改导出的 `theme.name`、`theme.mode`（`day` 或 `night`）及 `theme.variables` 中的色值，再点「导入美化」保存并应用；导入会切换到文件指定的日夜模式。多套自定义美化可同时保存，重复导入相同名称、模式和色值不会重复添加。内置美化保留，自定义美化可删除，选择内置配色即可恢复。

色值支持 `#RGB`、`#RGBA`、`#RRGGBB` 和 `#RRGGBBAA`。完整字段说明见 [THEMES.md](THEMES.md)。完整备份也包含自定义美化；合并备份保留当前选择，覆盖恢复还原备份中的选择。

## 数据与 API

API 通过酒馆服务器转发，因此请求通常不受浏览器跨域限制。当前仅支持 OpenAI 兼容的 `/chat/completions` 接口。

收藏、前后缀、组合、配色、提示词与 API 设置保存在当前酒馆用户的扩展设置中。密钥也只保存于该用户设置，**不包含在导出的备份中**。覆盖恢复后需要重新填写密钥；合并导入保留当前 API 设置。

每次生成会把上述角色资料、用户设定、最近聊天和本次脑洞发送到你填写的 API。角色卡里的系统提示词、越狱提示词及酒馆的聊天生成预设不被加入这次请求。

发送会填写 `#send_textarea` 并点击 `#send_but`，经过酒馆本身的用户消息处理、正则和宏替换流程。发送成功后会保留原先未发送的输入框草稿。生成后若切换了聊天，直接发送会提示重新生成；已保存的指令可以在当前聊天复用。

备份仅包含已保存内容，不包含尚未保存的脑洞、编辑草稿或生成结果。重要结果请先点击「保存」。

## 开发验证

核心单元测试：`npm test`（Node.js 20+，无需额外依赖）。测试覆盖角色上下文、独立 API 请求、输出解析、错误和取消；界面和酒馆发送接入另外用模拟环境验证。

首次使用仍需用自己的 API 和酒馆实例检查「测试连接」及发送效果。各服务对模型名、输出上限和思考模式的要求可能不同。
