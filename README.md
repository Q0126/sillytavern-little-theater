# 脑洞小剧场 · SillyTavern 扩展

输入脑洞 → 独立 API 整理成小剧场创作指令 → 编辑、保存 → 通过酒馆的用户发送键发出 → 当前角色创作小剧场。

## 安装

需要 SillyTavern 1.13.0 或更新版本，建议使用近期版本。

1. 在酒馆的「扩展」页面点「安装扩展」。
2. 粘贴本仓库的 GitHub 地址，安装完成后刷新酒馆。
3. 在扩展设置或输入框旁的扩展菜单中打开「脑洞小剧场」。面板以居中小窗显示，手机上保留四周边距，内容在窗口内滚动；可点击右上角「关闭」、按 Escape 或点击窗外返回聊天。
4. 在「API 设置」中填写 OpenAI 兼容的 API 基础地址和密钥，点击「连接 API」，从获取到的列表中选择模型，给配置起名，再点击「保存并使用」。可保存多组配置，切换时各自恢复地址、模型与密钥。原有配置会自动迁移。例如地址为 `https://api.example.com/v1`。

无需构建、npm 安装或酒馆助手。`manifest.json` 与 `index.js` 必须在仓库根目录；单独改 HTML 的文件名不能成为扩展。

## 功能

- 自动读取当前角色卡、用户设定和最近 20 条非系统聊天；群聊会读取成员资料。
- 独立请求 Chat Completions，使用本扩展的提示词预设和输出上限，不调用酒馆当前的聊天生成预设。
- 内置提示词将脑洞整理为「创作指令」，不预先生成故事正文。默认目标约 300 字，上限 1024 token；均可编辑、保存多组预设。
- 可一次生成 1–10 条，支持停止、编辑、重生成、保存和发送。发送后角色正常回复的阶段仍使用酒馆自己的聊天配置。
- AI 请求只使用脑洞与角色参考资料，不传入所选前后缀；生成结果可单独编辑。点击保存或发送时，按“所选前缀 → 生成指令 → 所选后缀”拼接，已保存的指令直接发送，不重复拼接。
- 新增“暂停正文 · 番外”“一次性写到结局”“字数不限”“禁止 OOC”条目。新条目会自动补进已有用户的库，保留自定义内容；删除后不会在刷新时重新添加。
- 前缀和后缀可新建、编辑、保存，多选叠加并调整顺序；可保存整个组合。选择窗口每排两条，约八条可见，继续向下滚动。
- 日间、夜间各四款配色，各自记住上次选择；支持导入自定义美化，导出当前选中的美化分享。
- 分别保存小剧场指令和角色回复；支持多标签、关键词和标签筛选，两个分类分别记住搜索条件。新增入口在对应分类搜索框下面。收藏卡片只读，点击「查看全文」打开阅读小窗，只有进入编辑后才显示「保存修改」。
- 角色回复支持酒馆格式化阅读和原文切换；样式放在独立窗口内展示，保留完整原文用于编辑和复制。可跳转关联指令或筛选关联回复。关联选择支持搜索，每排两条、最多八行，手机上按可用高度缩小后滚动。角色消息操作栏新增书签按钮，点击即可收藏当前回复；也支持手动粘贴收藏。
- 导出 / 导入 JSON 备份，可合并去重或覆盖恢复；支持先前界面预览版导出的备份。

## 更新日志

点击“脑洞小剧场”标题右侧的「更新日志」，在小窗中查看当前版本、发布日期和历次更新内容；每个版本默认折叠，点击版本才展开详细内容；往下滚动可看较早版本。扩展更新后，日志也会随新版本一起更新。

记录保存在 [changelog.json](changelog.json)，最新版本排在最上方。

## 自制与分享美化

在「美化」窗口选择配色，点击「导出当前美化」下载独立 JSON 文件。文件只包含这一套美化的名称、日夜模式和界面色值，不含 API 设置、收藏或聊天内容。

别人可修改导出的 `theme.name`、`theme.mode`（`day` 或 `night`）及 `theme.variables` 中的色值，再点「导入美化」保存并应用；导入会切换到文件指定的日夜模式。多套自定义美化可同时保存，重复导入相同名称、模式和色值不会重复添加。内置美化保留，自定义美化可删除，选择内置配色即可恢复。

色值支持 `#RGB`、`#RGBA`、`#RRGGBB` 和 `#RRGGBBAA`。完整字段说明见 [THEMES.md](THEMES.md)。完整备份也包含自定义美化；合并备份保留当前选择，覆盖恢复还原备份中的选择。

## 数据与 API

API 通过酒馆服务器转发，因此请求通常不受浏览器跨域限制。当前支持 OpenAI 兼容的 `/models` 模型列表和 `/chat/completions` 生成接口。连接只获取模型列表，不产生聊天正文。

收藏、前后缀、组合、配色、提示词与 API 设置保存在当前酒馆用户的扩展设置中。每组配置的密钥分别保存在该用户设置，**所有密钥都不包含在导出的备份中**。备份包含多组配置的名称、地址和模型。覆盖恢复会清空原有密钥，需为恢复后的配置重新填写；合并导入保留已有配置的密钥和当前 API 选择，新导入的配置需补填密钥。

每次生成会把上述角色资料、用户设定、最近聊天和本次脑洞发送到你填写的 API。角色卡里的系统提示词、越狱提示词及酒馆的聊天生成预设不被加入这次请求。

发送会填写 `#send_textarea` 并点击 `#send_but`，经过酒馆本身的用户消息处理、正则和宏替换流程。发送成功后会保留原先未发送的输入框草稿。生成后若切换了聊天，直接发送会提示重新生成；已保存的指令可以在当前聊天复用。

备份仅包含已保存内容，不包含尚未保存的脑洞、编辑草稿或生成结果。重要结果请先点击「保存」。

## 开发验证

核心单元测试：`npm test`（Node.js 20+，无需额外依赖）。测试覆盖角色上下文、独立 API 请求、输出解析、错误和取消，以及 API 配置迁移、备份字段限制、标签归并；界面和酒馆发送接入另外用模拟环境验证。

首次使用仍需用自己的 API 和酒馆实例检查「连接 API」、模型选择及发送效果。各服务对模型名、输出上限和思考模式的要求可能不同。
